# Business-Intelligence-Analysis-for-Retail-Food-Pricing-and-Sales-in-Malaysia
## Overview
A Business Intelligence project analyzing Malaysia’s food retail industry using PriceCatcher and historical retail sales data. The project focuses on food pricing trends, item distribution, retail premises, and sales performance through interactive dashboards to support data-driven decision-making.
